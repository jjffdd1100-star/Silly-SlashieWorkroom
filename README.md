# Silly-SlashieWorkroom

SillyTavern에서 채팅 편집·검색·비교·메모·탐색·유틸리티 작업을 슬래시 커맨드와 플로팅 패널로 빠르게 처리할 수 있는 올인원 작업실 확장입니다.

> - 전체 슬래시 커맨드 목록은 `/slashie`로 언제든 열어볼 수 있습니다. (분류순 / `A–Z` 정렬 지원)
> - 세부 설정(하이라이트 색상·위치, 추론 블럭 무시, 번역문 우선, 선택 삭제 UI, 스티키·인덱스 색상 등)은 `/edit` (또는 `/editmode`) 에서 조절합니다.

## 자동 백그라운드 편의 기능

- **캐릭터 시트 수정 가드**: 첫 인사말만 있는 새 채팅방에서 캐릭터 설명·노트 등 첫 인사말·이름과 무관한 시트 항목을 수정할 때 첫 메시지가 불필요하게 초기화/재생성되는 현상을 자동으로 막아줍니다.
- **수정·삭제 자동 스냅샷 (`/ctrlz`)**: 슬롯 설정을 `1~5`로 켠 경우(기본값 `0` · 꺼짐) 채팅 메시지 수정·삭제·스와이프 삭제 시 변경 내역을 브라우저 `localStorage`가 아닌 `user/files/slashie-undo-history.json` 경로에 자동 보관해 `/ctrlz`로 되돌릴 수 있습니다. 최대 5개 슬롯만 유지되고 24시간 후 자동 만료·삭제됩니다.
